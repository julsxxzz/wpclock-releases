# WPClock

The staff time clock and payroll app for **WP Esports Cafe**: staff clock in and out with a PIN,
the owner plans the roster, staff tick off their chores (with a phone photo where proof is
needed), and payroll is exported to Excel in one click.

This repository only holds the downloads.

## Download

Go to **[Releases](../../releases/latest)** and download **`WPClock-<version>.exe`** (the installer).

- Windows 10/11, 64-bit. Nothing else to install; Java is included.
- If Windows shows *"Windows protected your PC"*, click **More info → Run anyway**.
- If Windows asks whether to allow WPClock on the network, click **Allow** (so staff phones can
  send chore photos to the PC over the café Wi-Fi).

There's also a **portable zip** on each release: unzip it to a permanent folder and run
`WPClock.exe`, no installation needed.

## Updating

WPClock 1.2.1 and later tell the owner when a new version is available, show what's new, and
can install it. Updating is always optional. Each installer's SHA-256 is listed in its release
notes, and WPClock checks it before installing.

## Help

The **User Guide** (`USER_GUIDE.md`) is attached to every release and is built into the app:
"? How to use" on the front-desk screen, and the Help tab in the owner dashboard.
